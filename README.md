One emoji, picked to make a stranger smile: 🤗 — a smiling face with open arms, a hug offered to whoever sees it. Warm at first glance, understood everywhere with no irony, clearly a deliberate pick over the default smiley, and friendly rather than flirtatious. The program writes exactly that one emoji to `/output/entry.txt` and nothing else.

## Run it

```sh
node main.ts
```

It writes a single emoji (one code point, four UTF-8 bytes, no trailing newline) to `/output/entry.txt`, then reads it back and checks it holds exactly one emoji.
